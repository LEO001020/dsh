**The shared shape:** a mechanism is implemented, unit-tested, and correct — while
nothing in the product calls it. Every test passes because the test calls the
mechanism directly. This is the same failure as an oracle weaker than its
scenario, and it is the reason the launch-port and handover fixes each came with a
test that installs NOTHING.

**The standing check that finds it**, applied per module:

1. Build the import graph from the package's `exports` roots, not from a
   directory listing.
2. For each module, ask whether any NON-TEST importer reaches it.
3. If not, ask whether the product needs it. If yes, that is an unwired capability.
4. Write a test that exercises the PRODUCT path (a boot probe or a
   no-test-installed-seam test), because a direct-mount test cannot see this.
