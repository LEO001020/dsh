# DATA-11 — a page cursor is not a bearer token
########################################################################
ORACLE (v2): "Replay a valid cursor against a different store or a different revision.
... The cursor is refused and the refusal is recorded. A cursor that yields pages from
a store it was not issued for is NOT PASS."

$ node node_modules/vitest/vitest.mjs run src/data11-cursor-realm.test.ts
  Test Files  1 passed (1)
       Tests  32 passed (32)
  REFUSED: arm 3 refuses store A's cursor presented to store B holding the SAME bytes;
    "refuses the cross-store replay BEFORE any byte is read, so no unverified content
    escapes"; refuses a store holding DIFFERENT bytes under the same address; refuses
    even when the other store has no object at all. Arm 2 refuses a cursor after the
    grant revision moves. Arm 4 refuses a tampered, re-signed and realm-edited cursor.
  RECORDED: "journals a cross-store refusal durably, naming both realms and the step";
    "records the refusal through the request sink even when no journal is mounted";
    "maps every refusal code to the read-order step that produced it"; "keeps recording
    refusals across many attempts rather than only the first".
  DURABLE REALM: "survives a REAL process restart: the realm read by one process is
    the one a second process reads"; "lets a cursor minted before a restart resume
    after it, which a per-boot realm could not"; "refuses rather than silently minting
    a new realm when the realm file is malformed".
