VERDICT: this is the ONE protection git provides for free, and it is why each

=== AND THE HARDER FORM, which is why the code CHECKS rather than assumes ===
         Mutation 1 above moved the integration ref from inside the worktree.
         Branch separation stops the ORDINARY path, not a deliberate one, so the
         code re-reads the protected refs and refuses a publication whose ref
         moved. Detection is the honest claim; 'the writer cannot' is false here.
